# AVP-Dev Homebrew Tap

Official Homebrew repository for CLI tools and applications by [Aliaksei Patskevich (AVPDev)](https://avpdev.com).

## Usage

Install any application directly:

```sh
brew install AVP-Dev/apps/<formula>
```

Or add the tap first:

```sh
brew tap AVP-Dev/apps
```

## Available Formulas

| Formula | Description | Installation |
| :--- | :--- | :--- |
| **[talos](Formula/talos.rb)** | Local CLI-first orchestrator for AI coding agents with Team and Pair modes | `brew install AVP-Dev/apps/talos` |

## macOS Apps

| App | Installation |
| :--- | :--- |
| **[NYX Vox](https://nyx-vox.avpdev.com/)** (Apple Silicon) | `brew install --cask AVP-Dev/apps/nyx-vox` |
